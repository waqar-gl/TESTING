# DevOps Security Digest

Daily DevOps security report delivered to ntfy.

## Features

- High/Critical CVEs only
- Known Exploited Vulnerabilities
- Ubuntu Security Notices
- Docker Security
- GitHub Advisories
- AWS Status
- Cloudflare Status
- Anthropic Status
- Daily ntfy notification

## Setup

```bash
git clone ...

pip install -r requirements.txt
```

Copy

```text
config.example.yaml
```

to

```text
config.yaml
```

Subscribe to your ntfy topic.

Create GitHub Secret

```
NTFY_TOPIC
```

Done.
